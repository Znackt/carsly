## GETTING STARTED
- Get a computer or virtual machine
- Install nodejs^22 version on your machine

### Installation - Running
###### Step-1: Clone this repository
```bash
git clone https://github.com/Znackt/carsly.git
```

###### Step-2: Install
```bash
npm install
```

###### Step-3: Starting the dev server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
